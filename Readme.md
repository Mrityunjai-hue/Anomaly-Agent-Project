# E-Commerce Anomaly Agent

An end-to-end e-commerce analytics and AI-powered anomaly detection system built using the Olist Brazilian E-Commerce Public Dataset.

## Project Goals

The project will combine:

- Business and revenue analytics
- E-commerce KPI monitoring
- Anomaly detection
- Automated anomaly explanations
- Customer RFM analysis
- Customer churn prediction
- Business alerts
- Automated reporting

## Dataset

Olist Brazilian E-Commerce Public Dataset.

The dataset contains multiple relational tables covering orders, customers, products, sellers, payments, reviews and geolocation.

## Tech Stack

- Python

- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
